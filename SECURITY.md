# Segurança

O Claude Raio-X só lê arquivos locais do Claude Code (`~/.claude` e `~/.claude.json`), não escreve neles e não envia dados para a internet.

## Como relatar uma vulnerabilidade

Use o botão **Report a vulnerability** na aba **Security** deste repositório no GitHub (relato privado). Não abra issue pública com detalhes de falha ou com dados seus.

Inclua a versão do app, os passos para reproduzir e o impacto. A resposta inicial costuma sair em até 7 dias.

## Versões com suporte

Só a versão mais recente recebe correções.
